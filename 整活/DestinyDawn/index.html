在此介绍一下本人用 Godot 搓的回合制战棋卡牌游戏 —— 《DestinyDawn》。

本人革新派（狡辩：其实是高中牲时间不足）用了比较大量的 Vibe Coding ，项目有点史山，见谅

《DestinyDawn》是一款 3v3 回合制策略游戏。每局从多名角色中挑选 3 人组队，在六边形地图上与对手展开对战。移动、攻击、释放技能、使用卡牌 —— 活用每回合的有限行动来赢得胜利。

  • 回合制六边形战棋：在六边形格子上移动，讲究走位与站位
  • 卡牌构筑：每回合抽牌，拖拽卡牌即可释放，不消耗角色行动次数
  • 角色技能：每个角色都有独特的主动技能，带冷却回合，还有天赋系统
  • 支持双端：Windows 完整功能，Android 完整玩法 + 触摸适配

# 游戏流程

  1. 编队管理：从多名角色中选择 3 人组成队伍
  2. 卡组构筑：从多张卡牌中选择 8 张构成牌库
  3. 选择模式：单人游戏（对战 AI）、联机游戏
  4. 战斗：每回合先手顺序随机决定，双方轮流移动、攻击、释放技能，卡牌随时可独立释放，最后点击「结束回合」推进回合

胜负条件：全灭敌方所有角色即为胜利，结算界面还会展示双方伤害、治疗、卡牌使用和击杀统计。

# 操作方式

Windows 端：鼠标左键选择角色 / 移动攻击 / 使用技能 / 拖拽卡牌，右键拖拽地图，滚轮缩放，F 键收起手牌，ESC 打开投降菜单。

Android 端：单指点击 / 拖拽操作，双指捏合缩放，双指拖动平移视角，「手牌」「菜单」按钮管理界面。

# 联机对战

  • 同一局域网：房间码自动显示本地 IP，直接加入
  • 跨网联机（推荐）：使用 EasyTier（免费开源组网）或蒲公英（贝锐，免费 3 设备），双方加入同一虚拟网络，房间码自动识别虚拟 IP，输入房间码即可对局

安卓端受移动 NAT 限制，跨网对局请使用上述组网方式；若连不上，检查双方防火墙放行 UDP 1145 端口。

# 下载

  • GitHub 仓库：5652fsft/DestinyDawn
  • 下载：GitHub Releases 页面

Windows 版支持自动更新（检测新版本 → 下载 → 替换重启），更新下载采用 8 段并发，速度提升明显。网络不便直连 GitHub 时，可在设置里切换镜像更新通道。设置、编队、卡组都会自动保存到本地，重启游戏后保留。
